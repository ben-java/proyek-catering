## 3. Perubahan yang dikerjakan

### 3.1 Mode gelap (`prefers-color-scheme: dark`)
- `public/css/app.css`: seluruh token warna (`--surface`, `--text`, `--line`, status tag, tombol, bayangan) punya nilai gelap; `color-scheme:dark` agar kontrol bawaan browser ikut gelap.
- `--appbar-bg` ditambahkan supaya appbar tetap hijau tua saat `--accent-strong` menjadi mint terang di mode gelap.
- `public/css/storefront.css`: palet earthy (`--terra`, `--peach`), kartu "occasion", label foto, dan panel konfirmasi ikut gelap.
- Verifikasi: screenshot `30-dashboard-dark.png`, `31-storefront-dark.png`; kontras 0 gagal.

### 3.2 Gaya cetak untuk laporan
- `@media print`: sembunyikan appbar/footer/filter/tombol; warna jadi hitam-putih; tabel tidak terpotong antar halaman (`break-inside:avoid`, `thead` diulang); URL absolut ditampilkan setelah tautan.
- Token khusus cetak: `--text-muted:#333`, angka statistik 16pt, ikon statistik disembunyikan.
- Tombol **Cetak** ditambahkan di `/laporan/porsi` dan `/laporan/pendapatan` (skrip ber-nonce → `window.print()`).
- Verifikasi: `33-porsi-print-v2.png`.

### 3.3 Aksesibilitas
- Filter `/pesanan` dan `/menu`: `label` kini terhubung ke kontrol (`for`/`id`).
- Halaman detail pesanan: nomor pesanan menjadi `<h1>` (sebelumnya tidak ada `h1`), `label` untuk select status, checkbox konfirmasi 26×26 px.
- Tautan kredit foto storefront: `min-height:26px` + padding agar memenuhi target sentuh.
- Verifikasi: `a11y.mjs` → 0 isu di 8 halaman.

### 3.4 Keamanan yang bersinggungan dengan tampilan
- Nonce CSP membuat `onsubmit="return confirm(...)"` tidak berjalan. Diganti: `data-confirm` pada form + listener global di skrip ber-nonce.
- Diuji via CDP: `confirm()` dipanggil dengan pesan benar dan `submit` dibatalkan saat pengguna menolak.
- Pelanggaran CSP yang tersisa di konsol berasal dari skrip injeksi alat pengujian (`<script id="browser-logger-active">` baris 12 dokumen), bukan dari kode aplikasi — semua `<script>` aplikasi memakai nonce yang sama dengan header.

## 5. Yang sengaja belum dikerjakan

1. `style-src` CSP masih `'unsafe-inline'` karena puluhan atribut `style="…"` inline; menutupnya butuh memindahkan semua ke `resources/css` (refactor terpisah, bukan tambal).
2. Gambar menu di storefront memakai `loading="lazy"`; pada screenshot `captureBeyondViewport` sebagian kartu tampak kosong karena belum masuk viewport — perilaku normal, bukan bug.
3. Mode gelap mengikuti preferensi sistem; belum ada tombol pilih tema manual.
